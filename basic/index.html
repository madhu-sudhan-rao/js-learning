JS Basic

  1. Display Current Day and Time

    Write a JavaScript program to display the current day and time in the following format.

  2. Print Current Window Contents

    Write a JavaScript program to print the current window contents.

  3. Get Current Date in Various Formats

    Write a JavaScript program to get the current date.

  4. Calculate Area of Triangle (Sides: 5, 6, 7)

    Write a JavaScript program to find the area of a triangle where three sides are 5, 6, 7.

  5. Rotate String 'JavaScript' Periodically

    Write a JavaScript program to rotate the string 'JavaScript' in the right direction. This is done by periodically removing one letter from the string end and attaching it to the front.

  6. Find Years When Jan 1 is Sunday (2014?2050)

    Write a JavaScript program to find out if 1st January will be a Sunday between 2014 and 2050.

  7. Random Integer Guess Game

    Write a JavaScript program where the program takes a random integer between 1 and 10, and the user is then prompted to input a guess number. The program displays a message "Good Work" if the input matches the guess number otherwise "Not matched".

  8. Get Current Website URL

    Write a JavaScript program to get the website URL (loading page).

  9. Create Variable with User-Defined Name

    Write a JavaScript exercise to create a variable using a user-defined name.
